# Portfolio académico · GitHub Pages

Ejemplo de portfolio oscuro para el trabajo de clase.

## Publicarlo
1. Crea un repositorio en GitHub.
2. Sube todos los archivos manteniendo la estructura.
3. Ve a Settings → Pages.
4. En Build and deployment selecciona `Deploy from a branch`.
5. Elige `main` y `/ (root)`.
6. Guarda y espera a que GitHub Pages publique la web.

## Importante
El contenido de los Hitos 1, 2 y 3 contiene campos de ejemplo para que sustituyas el texto por tus propias tareas y reflexiones.
