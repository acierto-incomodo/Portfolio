PUNTO DE PARTIDA

¿Dónde estoy?

Originalmente vengo de estudiar un bachiller tecnologico aunque actualmente soy un estudiante de desarrollo de aplicaciones multiplataforma (DAM) con inteeres en la programación y el desarrollo de proyectos tecnológicos.

Parto de una pequeña experiencia de aprendizaje autonomo desde que tenia aproximadamente 14 años, desarrollando paginas web simples y continuando hasta la actualidad desarrollando programas simples para escritorio.

META

¿Dónde quiero llegar?

Quiero terminar mi formación con una base técnica sólida y capacidad para trabajar en equipo como desarrollador de aplicaciones multiplataforma.

APRENDIZAJE PARALELO

Aprender por mi cuenta

Fuera del aula sigo aprendiendo por mi cuenta, aprendiendo nuevas tecnologias y perfeccionando mis conocimientos actuales en programación.

A lo largo de mi aprendizaje autonomo e aprendido diferentes lenguajes de programacion, por ejemplo HTML, CSS, JS, Node JS y Python.

Ademas, a lo largo de los años e utilizado tanto como el sistema operativo Windows 10/11 como Linux en sus diferentes distribuciones.

Tambien e llegado a aprender a utilizar diferentes herramientas para desarrollar con mas facilidad e incluso para ser mas eficiente pudiendo acceder desde diferentes dispositivos. Entre todos los programas utilizados, principalmente utilizo Visual Studio Code para programar y GitHub Desktop (Git con diseño grafico) para poder mantener mis proyectos en la nube completamente sincronizados para acceder desde cualquier dispositivo en cualquier parte del mundo.

OBSTACULOS

Cuando algo no funciona

Uno de mis retos principales es intentar resolver los problemas en los que me quedo atascado a la hora de realizar diversos proyectos. Mi estrategia principal es intentar encontrar el problema y buscar diferentes formas de resolverlo de forma eficiente y documentar lo sucedido y como lo e resuelto.

Otro de mis obstaculos seria el ingles. Tengo la intencion al menos conseguir el nivel B2, y si es posible conseguir el nivel C1 para tener un buen nivel de ingles para utilizarlo cuando sea necesario sin problemas.

Si mi primera opcion profesional no sale como esperaba, tengo la intencion de seguir formandome con diferentes alternativas de estudio. Por ejemplo realizar el grado superior de desarrollo de aplicaciones web (DAW) o administrador de sistemas informaticos en red (ASIR).
